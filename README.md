# TekXpat/.github

This repository supplies TekXpat's public organisation profile (`profile/README.md`) and the default community files every TekXpat repository inherits: contributing guide, code of conduct, security policy, and pull request and issue templates (all under `.github/`).

A repository that has its own file of the same type uses that instead. For issue templates the override is all-or-nothing: a repository with any templates of its own uses none of these.

This repository is public. Nothing in it should name clients or projects, or describe infrastructure.

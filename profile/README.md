# TekXpat

TekXpat is a software company. We build web applications, business systems and the infrastructure that runs them, and we keep running what we ship after it goes live.

### What we do

- **Web applications.** Customer-facing products and internal tools, from first prototype to production.
- **Business systems.** Finance, operations and workflow software shaped around how an organisation actually works, not the other way round.
- **Websites.** Fast, accessible sites built to be found in search.
- **Managed infrastructure.** Hosting, monitoring, backups and updates, so systems stay healthy long after launch.

### How we work

Every change is reviewed before it ships. We test the things that matter, and when something goes wrong we say so early instead of hoping nobody notices.
